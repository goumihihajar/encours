# Projet interactif AMSD

Site statique avec carte D3 pour la visualisation des régions marocaines.

## Déployer sur GitHub

1. Créez un dépôt distant sur GitHub :
   - allez sur https://github.com/new
   - nommez-le `projet-encours` ou comme vous le souhaitez
   - laissez l’option `Add a README` décochée si vous utilisez celui-ci

2. Ajoutez le dépôt distant localement :
   ```bash
   git remote add origin https://github.com/<votre-utilisateur>/<nom-du-repo>.git
   git branch -M main
   git push -u origin main
   ```

3. Pour publier le site avec GitHub Pages :
   - allez dans `Settings > Pages`
   - choisissez la branche `main`
   - sauvegardez

4. Votre site sera disponible à l’adresse :
   `https://<votre-utilisateur>.github.io/<nom-du-repo>/`
